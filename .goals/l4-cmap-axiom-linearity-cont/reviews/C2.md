## Counterexample hunt

### The unconditional `instance` over arbitrary α, β
Iter-04 claims provable unrealizability. The reasoning sketch: for `(x_k)` taken to be `x_k(x_*) := x_*^k` (the monomials, a computable sequence under polynomial form: `aX(k, m, j) := if j = k then 1 else 0`, `dX(k, m) := k`), we have `‖x_k‖_∞ = max(|α|, |β|)^k`. For arbitrary `α, β`, no Computable ℕ-function of k can bound this. A linear-combination like `s n := Σ_{k ≤ d n} (1 · x_k + 0)` (i.e. `coefα(n, k) = 1`, `coefβ(n, k) = 0`) would need an `aS, dS` witness with bound `‖s n - polyApproxCMap aS dS n m‖ ≤ 1/2^m`. The polynomial expansion `polyApproxCMap aS dS n m = Σ_k polyApprox aX dX k M = Σ_k x^k` (since x_k IS its own polyApprox). So the bound becomes `0 ≤ 1/2^m`, trivially satisfied — **so the unconditional case is provable here**.

This indicates the iter-04 obstruction analysis was specific to the *bound strategy* using `bound_x_k` (which scales as `max(|α|, |β|)^k`), not to the existence of *any* witness. The unconditional form may yet be provable by a smarter strategy. The restructure is conservatively justified, but the iter-04 claim of "provable unrealizability" is too strong.

### Sound, but: is the +6 constant in `stuff_per_k` enough?
Per-k summand bound (α-side):
`|coefα · x_k - αR(·, M) · polyApprox aX dX k M|`
≤ `|coefα - αR(·, M)| · ‖x_k‖_∞ + |αR(·, M)| · ‖x_k - polyApprox aX dX k M‖_∞`
≤ `2^{-M} · bound_x_k(k) + (bound_αR_at_0(n, k) + 2) · 2^{-M}`
= `2^{-M} · (bound_x_k + bound_αR_at_0 + 2)`.

Where `|αR(·, M)| ≤ |αR(·, 0)| + |αR(·, M) - αR(·, 0)| ≤ bound_αR_at_0 + (2^{-M} + 2^{-0}) ≤ bound_αR_at_0 + 2`.

Plus β-side: `2^{-M} · (bound_y_k + bound_βR_at_0 + 2)`.

Sum: `2^{-M} · (bound_x_k + bound_y_k + bound_αR_at_0 + bound_βR_at_0 + 4)`.

`stuff_per_k - sum = 6 - 4 = 2` units of slack. ✓ Plenty.

### M's algebra
`M = m + (d n + 1) + bound_max(n) + 2`. Need `2^{-M} · 2 · (d n + 1) · bound_max(n) ≤ 1/2^m` (the factor 2 for α+β sides).

`2^{-M} · 2 · (d n + 1) · bound_max(n) = 2^{-m} · 2^{-(d n + 1)} · 2^{-bound_max(n)} · 2^{-2} · 2 · (d n + 1) · bound_max(n)`
= `2^{-m} · [(d n + 1) / 2^{d n + 1}] · [bound_max(n) / 2^{bound_max(n)}] · 1/2`.

Both brackets ≤ 1 (since `2^k ≥ k` for all `k ≥ 0` and `2^{k+1} ≥ k + 1` for `k ≥ 0`). So total ≤ `2^{-m} / 2 = 2^{-m-1} ≤ 2^{-m}`. ✓ Algebra checks out with factor 2 slack.

### bound_x_k k ≥ 1
`bound_x_k k = 1 + Σ_j bound_aX_at_0(k, j) · B^j ≥ 1 > 0`. So `bound_max ≥ stuff_per_k = bound_x_k + bound_y_k + ... + 6 ≥ 1 + 1 + 0 + 0 + 6 = 8` for any `n` with `d n ≥ 0`. So the `2^{bound_max(n)}` factor in M's expansion is ≥ 256. ✓

### `bound_aX_at_0` IS an upper bound on `|aX(k, 0, j)|`?
`aX(k, 0, j) = aX ((Nat.unpair m).1, (Nat.unpair (Nat.unpair m).2).1, (Nat.unpair (Nat.unpair m).2).2)` for `m = Nat.pair k (Nat.pair 0 j)`. Unpacking: `Nat.unpair m = (k, Nat.pair 0 j)`, `Nat.unpair (Nat.pair 0 j) = (0, j)`. So this equals `aX(k, 0, j)`. ✓

`|aX(k, 0, j)| : ℚ = aX_a(m) / aX_b(m)` where `m = Nat.pair k (Nat.pair 0 j)`. Since `aX_b(m) ≥ 1` (from `aX_b m ≠ 0` and `aX_b : ℕ → ℕ`), `|aX(k, 0, j)| ≤ aX_a(m) = bound_aX_at_0(k, j)`. ✓

**Subtle**: the cast to ℝ preserves this `≤`, so as a ℝ-bound it holds. The bound proof uses this in `‖polyApprox aX dX k 0‖_∞ ≤ Σ_j |aX(k, 0, j)| · |x_*|^j ≤ Σ_j bound_aX_at_0(k, j) · B^j`. ✓

### Empty domain (α > β)
`Set.Icc α β = ∅` when `α > β`. `C(∅, ℝ)` is essentially a singleton, with all sup-norms = 0. The bound `0 ≤ 1/2^m` is trivial. Mathlib's `ContinuousMap.norm_le` (Compact.lean:204) does NOT require `Nonempty α` — it just needs `0 ≤ C`. So the bound proof can handle this directly without case-split. ✓ Not an obstruction.

### α = β (singleton domain)
`Set.Icc α β = {α}`. `‖f‖ = |f(α)|`. The polynomial `polyApprox aX dX k m` evaluates at `α` to a fixed rational sum, computable. Bound proof goes through. ✓

### B = 0
Forces `α = β = 0` (from `|α| ≤ 0` and `|β| ≤ 0`). Singleton domain `{0}`. `bound_x_k k = 1 + bound_aX_at_0(k, 0) · 0^0 = 1 + bound_aX_at_0(k, 0)` (since `0^0 = 1` in ℕ but `0^j = 0` for `j ≥ 1`). Bound proof: at `x_* = 0`, `polyApprox aX dX k 0 (0) = aX(k, 0, 0)`, `‖polyApprox‖_∞ = |aX(k, 0, 0)| ≤ bound_aX_at_0(k, 0)`. So `‖x_k‖_∞ ≤ 1 + bound_aX_at_0(k, 0) = bound_x_k(k)`. ✓ Edge case handled.
