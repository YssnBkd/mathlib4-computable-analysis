# Restatement

The theorem `l2_mul_gl` proves: if `f g : C(Set.Icc α β, ℝ)` are both
`IsGLComputable` (Grzegorczyk–Lacombe Definition A), then `f * g` is also
`IsGLComputable`. The proof extracts uniform bounds `M_f := ⌈‖f‖⌉₊ + 1`,
`M_g := ⌈‖g‖⌉₊ + 1` via the `ContinuousMap` `Norm` instance on a compact
`Set.Icc α β` (carrying `compactSpace_Icc`). The modulus witness is
`d_mul N := df (N + 1 + M_g) * dg (N + 1 + M_f)`. Boundedness on each
term combined with `M_k ≤ 2^M_k` (`Nat.lt_two_pow_self.le`) collapses
`M_k · 2^{-(N+1+M_k)} ≤ 2^{-(N+1)}`, and the two halves sum to `2^{-N}`
via `1/2^(N+1) + 1/2^(N+1) = 1/2^N` (`pow_succ; ring`).

## Hypothesis weakening

- *Drop `[CompactSpace ↥(Set.Icc α β)]`*: `‖f‖` becomes ill-defined (the
  `Norm` instance comes from `Compact.lean`). The `Bounded`-variant
  `norm_coe_le_norm` requires bounded codomain; on a non-compact domain,
  `C(X, ℝ)` need not be normed at all. So compactness is essential and is
  used precisely once, via the boundedness extraction.
- *Replace `M_f` by `⌈‖f‖⌉₊`* (drop the `+ 1`): then `M_f = 0` when
  `‖f‖ = 0` (e.g. on the empty interval, or when `f ≡ 0`). The positivity
  `0 < M_f` would fail, breaking `Nat.mul_pos` for `d_mul`. The `+ 1`
  cushion is load-bearing.
- *Drop the `Nat.lt_two_pow_self` step (`M_k ≤ 2^M_k`)*: then
  `M_k / 2^(N+1+M_k) ≤ 1/2^(N+1)` no longer holds in general (it would
  require `M_k ≤ 2^M_k`). Step is load-bearing.
- *Use `df(N) * dg(N)` instead of `df(N+1+M_g) * dg(N+1+M_f)`*: the
  refinement `N+1+M_*` is required: (a) the `+M_*` shift gives the extra
  `2^M_*` factor in the denominator absorbing `M_*`; (b) the `+1` halves
  each term so the sum is `1/2^N`, not `2/2^N`. Both shifts load-bearing.

## Counterexample hunt (fragile-step probe for a proof)

- *Empty-domain edge case (`α > β`)*: `Set.Icc α β = ∅`. The
  `CompactSpace` instance still holds (vacuous). `C(∅, ℝ)` is a singleton
  (the empty function), so `f = 0`, `‖f‖ = dist f 0 = 0`. Then
  `M_f = ⌈0⌉₊ + 1 = 1 > 0`. The `h_f_bnd` clause `∀ x : ∅, |f x| ≤ 1` is
  vacuously true. The modulus implication is vacuous over an empty domain.
  Predicate holds vacuously; no case-split needed. ✓
- *Degenerate `f = 0`*: `‖f‖ = 0`, `M_f = 1`. `|f x| = 0 ≤ 1`. The bound
  is loose but valid; no issue. ✓
- *Singleton domain `α = β`*: `Set.Icc α α = {α}`; `f` is constant.
  `|f x − f y| = 0 ≤ 1/2^N` always; modulus implication trivially holds.
  Boundedness extraction still works. ✓
- *Probe of the term `h_step1`*: needs `mul_le_mul (|f x| ≤ M_f) (|g x − g y| ≤ 1/2^(N+1+M_f)) (0 ≤ |g x − g y|) (0 ≤ M_f)`.
  Cross-check: the second argument is `h_g_mod`, which gives
  `|g x − g y| ≤ 1 / 2^(N + 1 + M_f)` (because `dg` was applied with
  argument `N + 1 + M_f`). The asymmetric cross-pairing
  (`|f x|`-bound paired with `g`-modulus and vice versa) is correctly
  reflected in the modulus shape `df (N+1+M_g) * dg (N+1+M_f)`. ✓

   updating the spec text in `current-goal.md` to reflect the
