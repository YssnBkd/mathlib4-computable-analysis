# Restatement

For `f, g : C(Set.Icc α β, ℝ)`, if both satisfy Pour-El & Richards Definition A
(`IsGLComputable`), then so does the pointwise difference `f - g`. The proof is
a two-line corollary: rewrite `f - g` as `f + (-g)` via the canonical
`SubNegMonoid` axiom `sub_eq_add_neg`, then close with the round's previously
proven structural closures `l2_sum_gl` and `l2_neg_gl`. No new mathematical
content; pure plumbing across an `AddGroup` reduction.

## Hypothesis weakening

- **Drop `hf`**: requires `IsGLComputable (-g) → IsGLComputable (f - g)`
  for arbitrary continuous `f`. Counterexample: any non-computable continuous
  `f : C(Set.Icc 0 1, ℝ)` (e.g., `f := fun x => r` for `r ∈ ℝ` non-computable,
  which is `IsGLComputable`-false because clause (i) demands the constant
  sequence `fun _ => r` be in `IsComputableSeqReal`, but for non-computable
  `r` it isn't). Then `f - g` cannot be `IsGLComputable` (apply the predicate
  to `g = 0`: `f - 0 = f`). So `hf` is necessary.
- **Drop `hg`**: symmetric — set `f = 0` and the argument transposes.
- **Weaken `hf` to "`f` continuous only"**: same counterexample.
- Both hypotheses are tight.
