# Restatement
The theorem `IsComputableSeqReal.neg` states: if a real sequence `a : ℕ → ℝ` is pointwise-effectively approximable by a computable double sequence of rationals to precision `1/2^k`, then so is the pointwise negation `fun n => -(a n)`. The proof routes through the §2.5 workhorse `isComputableSeqReal_of_effectiveConvergence`, with rational double-sequence witness `r(p) := - ra p` and effective modulus `e(p) := p.2` (the *unshifted* identity-on-precision modulus — no `+1` is needed because `abs_neg` preserves magnitude exactly). The proof has three obligations: (a) computability of the double sequence reduces to `IsComputableSeqRat.neg` on the `Nat.unpair`-flattened rational form; (b) computability of `e` is `Computable.snd`; (c) the convergence bound is established by rewriting `|((- ra (n, k) : ℚ) : ℝ) - (-a n)| = |((ra (n, k) : ℝ)) - a n|` via cast distribution + `abs_neg`, then chaining the original bound `hra_bnd n k ≤ 1/2^k` with `1/2^k ≤ 1/2^N` (from `pow_le_pow_right₀` + `one_div_le_one_div_of_le` applied to `hk : k ≥ N`).

## Hypothesis weakening
- Drop `ha`: cannot extract `ra` or `hra_bnd`; proof body collapses. Essential. ✓
- Weaken modulus from `e(p) := p.2` to `e(p) := 0` (constant): would require `|(- ra(n, 0)) - (-a n)| ≤ 1/2^N` for every `N`, which is impossible since `ra(n, 0)` is a fixed approximation with fixed error (could exceed any `1/2^N` for large `N`). Not sound.
- Strengthen modulus from `e(p) := p.2` to `e(p) := p.2 + 1`: still works (with slack); but the unshifted `p.2` is the tight minimum because `abs_neg` is *exact* (no error inflation, unlike `add` where triangle inequality doubles the error).
- Could one use the *bare* `Computable.snd` for `e` (no `+1`), and is `Computable.snd` even reachable here? Yes — `Computable.snd : Computable (@Prod.snd ℕ ℕ)` is exactly what's needed; the proof uses it directly. ✓
- The choice `e(n,N) := N` (unshifted) is the *minimal* sound modulus. ✓ This contrasts cleanly with `.add` where `N + 1` is required.

## Counterexample hunt
- Try `a = fun _ => 0`: trivially computable; negation is `fun _ => 0`, trivially computable. ✓ (sanity passes)
- Try `a = fun n => (1 : ℝ)`: computable via `IsComputableReal.ofRat 1`. Negation is `fun n => -1`, computable via `ofRat (-1)`. ✓
- Try `a = fun n => 1/(n+1 : ℝ)`: a computable real sequence (rational, hence each `r(n,k) := 1/(n+1)` with bound `0 ≤ 1/2^k`). Negation `fun n => -1/(n+1)` is computable. The proof produces witness `r(n,k) := -1/(n+1)` with bound `|-1/(n+1) - (-1/(n+1))| = 0 ≤ 1/2^N`. ✓
- Try `a` computable but with very fast-converging rationals (e.g., `a = fun n => √2`, witness `ra(n,k)` = `k`th rational convergent of √2): `IsComputableSeqReal a` holds; negation `fun n => -√2` has witness `r(n,k) := -ra(n,k)` with same precision. ✓
- Try `a` non-computable (e.g., the characteristic function of the halting set lifted to ℝ): hypothesis `ha` fails to typecheck. No proof goes through, so the negation closure cannot incorrectly conclude. ✓
- No structural counterexample emerges.
