## Modulus engineering verification

- `h_Lip_2m_le_K`: `Lip · 1/2^mm ≤ 1/2^K`. With `mm = Lip+k+3`,
  `2^mm = 2^Lip · 8 · 2^k`, so `Lip/2^mm ≤ 2^Lip/2^mm = 1/(8·2^k) = 1/2^(k+3)
  ≤ 1/2^(k+2) = 1/2^K`. ✓
- `h_Lip_BpKg_bound`: `Lip · 2(B+1)/kg ≤ 1/2^K`. With `kg = 8·Lip·(B+1)·2^k+1`,
  `Lip · 2(B+1)/kg ≤ Lip · 2(B+1) / (8·Lip·(B+1)·2^k) = 1/(4·2^k) = 1/2^K`. ✓
- Combined `h_combined_bound`: `Lip · (1/2^mm + 2(B+1)/kg) ≤ 2/2^K`. ✓
- Degenerate `Lip · 2/2^mm ≤ 2/2^K`: equivalent to `Lip/2^mm ≤ 1/2^K`,
  same as `h_Lip_2m_le_K`. ✓
