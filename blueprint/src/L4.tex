\begin{theorem}
  \label{thm:l4_cmap_instance}
  \lean{ComputableAnalysis.L4.computabilityStructureCMap_of}
  \uses{def:l3_computabilityStructure}
  $C([a,b], \mathbb{R})$ with sup-norm carries a \texttt{ComputabilityStructure}~$\mathbb{R}$ structure via the polynomial-approximation predicate, parameterized over an explicit rational bound $B$ on $\max(|a|,|b|)$ (matching P-R Ch.\,2:128's restriction to recursive reals).

  \textbf{Formalization state (2026-06-03, partial --- \texttt{axiom\_linearity} closed).} The witness $\langle aS, dS \rangle$ for \texttt{axiom\_linearity} is constructed and Computable; the \texttt{IsComputableSeqRat (flatten aS)} proof is closed (via \texttt{FinsetSumHelper.finsetSum\_rat} + helpers); and the polynomial-approximant norm bound $\|s_n - \texttt{polyApproxCMap}\ aS\ dS\ n\ m\| \le 1/2^m$ is now \emph{proved sorry-free}. The bound uses precision pad $M(n,m) = m + (d\,n{+}1) + \texttt{bound\_max}\,n + 2$, a per-summand triangle bound (\texttt{perk\_bound}: $|c_\alpha x - \alpha_r p| \le \varepsilon(C_a + P_x)$) over the polynomial-expansion identity, $\mathbb{N}$-valued coefficient/norm bounds (\texttt{bound\_x\_k}, \texttt{bound\_max}), and the close-out $\texttt{closeout\_nat}: (D{+}1)\,B_m\,2^m \le 2^{m+(D+1)+B_m+2}$. Thus \texttt{axiom\_linearity} (= P-R Axiom~1, Linear Forms) is complete for the first concrete instance on an infinite-dimensional space. \texttt{axiom\_limits} (= P-R Ch.\,0 Thm.\,4) and \texttt{axiom\_norms} (= P-R Ch.\,0 Thm.\,7) remain stub, so the declaration retains \texttt{sorryAx} and this node stays white-bordered (no \texttt{\textbackslash leanok}) until A2/A3 land. P-R Ch.\,2:141--153.
  See \texttt{ComputableAnalysis/L4/Instances/CMap.lean:634}.
\end{theorem}
