## Key findings

- **Mathlib `1/0 = 0` convention is a predicate-design trap.** Encoding "$1/d(N)$ defined" as an explicit `∀ N, 0 < d N` conjunct is *load-bearing* for `IsGLComputable`'s mathematical content. Without it, the existential `∃ d, …` is satisfied by `d := fun _ => 0` for any `f` (the antecedent `|x − y| ≤ 0` forces `x = y`, the conclusion holds trivially), collapsing Def A to Banach-Mazur (sequential computability alone). The iter-05 → iter-06 fix established this convention for the L2 layer.
- **`Computable.nat_rec` for `fun N => 2^N` works with the `show`-bridge.** `Primrec.nat_pow` does not exist in current Mathlib (per `docs/PITFALLS.md §1`); the inline recipe at `l2_id_gl` follows the established `h_Bpow` pattern from `L4/Instances/CMap.lean:1316-1329`.
- **Mathlib renames in current `v4.31.0-rc1` snapshot**: `abs_add → abs_add_le`, `div_le_div_iff → div_le_div_iff₀`. The `_le` and `_₀` suffixes signal "without bundled OrderedField" / "no-divisor-zero" variants becoming primary. Worth documenting in `docs/PITFALLS.md` for future rounds.
- **Modulus product `df(N+1)·dg(N+1)` is the natural sum-closure witness.** The `+1` shift is essential: at level `N`, each summand needs error `≤ 1/2^(N+1)` so the triangle inequality lands at `1/2^N`. Without the shift, the bound is only `1/2^(N-1)`.
- **Modulus invariance under negation.** `-f` reuses `df` verbatim; the `(∀ N, 0 < d N)` positivity travels through unchanged. This generalizes: any operation that preserves `|·|`-magnitude pointwise (negation, reflection) can reuse moduli unchanged.
- **`ContinuousMap.Algebra` is the home for `Add`/`Neg` instances on `C(X, ℝ)`.** `Topology/ContinuousMap/Basic.lean` alone does not bring `Add C(X, R)` into scope; the `.Algebra` import is needed and `(f + g) x = f x + g x` / `(-f) x = -(f x)` both reduce by `rfl` via the `@[to_additive]`-generated lemmas.
- **Private helpers in L2 for missing L1 closures is acceptable.** `IsComputableSeqReal.add` and `IsComputableSeqReal.neg` are not (yet) named lemmas in L1 (only `IsComputableSeqRat.add` and `.neg` are). Inlining them as `private` in L2 with a docstring TODO for the L1 lift is the pragmatic path.
- **Blueprint convention**: layer-prefix labels `l<N>_<name>` (matching L1/L4) are the project convention; the criterion's `def:isGLComputable` was transcription shorthand.
